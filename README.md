# 🎓 Early Dropout Prediction System

An AI-powered web application that helps educational institutions identify students who are at risk of dropping out by analysing academic and behavioural data. The system enables early intervention through predictive analytics, interactive dashboards, and detailed reports.

---

## 📌 Overview

The Early Dropout Prediction System uses Machine Learning techniques to predict whether a student is at risk of dropping out based on factors such as attendance, academic performance, assignment completion, and other student records. The platform assists institutions in making data-driven decisions to improve student retention.

---

## ✨ Features

- 📊 Student Performance Dashboard
- 🤖 AI-Based Dropout Risk Prediction
- 📁 Upload Student Data (CSV/Excel)
- 📈 Data Visualisation & Analytics
- ⚠️ Risk Classification (Low, Medium, High)
- 📝 Intervention Tracking
- 📄 Download Prediction Reports
- 🔒 Secure Role-Based Access
- 📱 Responsive User Interface

## 📊 Prediction Workflow

1. Upload student data (CSV/Excel).
2. System validates and preprocesses the data.
3. Machine Learning model analyses the records.
4. Students are classified into risk categories.
5. Dashboard displays prediction results and analytics.
6. Download prediction reports for further analysis.
